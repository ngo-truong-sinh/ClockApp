# ClockApp

A simple desktop clock application built with **Python** and **Tkinter**, compatible with **Windows 10 and 11**. The application includes four distinct time-related functions—**current time clock**, **stopwatch**, **countdown timer**, and **alarm** — each presented with a clean, dedicated interface.

## Features

- **v1.0.0**: Display current system time continuously.
- **v1.1.0**: Basic stopwatch functionality with Start, Stop, Reset.
- **v1.1.1**: Enhanced stopwatch with mark feature, fixed UI issues.
- **Future (v1.2.0)**: Timer (countdown) functionality.
- **Future (v1.3.0)**: Alarm (notification) functionality.
- **Future (v2.0.0)**: Separate UI for Clock, Stopwatch, Timer, and Alarm with bottom navigation buttons.

## Setup

1. Ensure Python 3.x is installed.
2. Run `clock.py` from the `versions/v1.1.0/source_code/` directory.
