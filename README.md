# ClockApp

A simple desktop clock application built with Python and Tkinter, compatible with Windows 10 and 11. The application supports displaying the current system time, with basic controls (Start, Stop, Reset).

## Features (v1.0.0)
- Display current system time in `hour:min:sec:millisecond` format.
- Basic controls: Start, Stop, Reset.

## Setup
1. Ensure Python 3.x is installed.
2. Run `clock.py` from the `versions/v1.0.0/source_code/` directory.

## Future Features
- Timer, countdown, and stopwatch.
- Audio notifications.
- Pin window on top.
- Settings menu for customization.
