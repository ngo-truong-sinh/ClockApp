#Changelog

##[1.0.0] - 2025-06-27
###Added
Initial release with system time display (hour:min:sec:millisecond).
Simple Tkinter GUI with fixed window size (400x200).
###Changed
Removed Start, Stop, Reset buttons as they are not suitable for the current clock function.
Clock now runs continuously without manual control.
